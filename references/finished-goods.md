# Finished goods: targeted follow-up

1. Start with user-specified or previously identified material IDs, weeks, site and scenario. Reuse that earlier shortlist as **prior-read evidence** when the user asks 'which finished goods do those shortages affect?' Do not re-read all 26 weeks unless a fresh full inventory report is requested; do not claim earlier figures were refreshed.
2. Read the **complete supplied HPE BOM PDF** (46 lines across six systems in the supplied version), not just retrieved snippets, before claiming complete FG coverage. If it is unavailable, stop. Exact Anaplan Code match or documented exact SKU crosswalk only; list and exclude unmatched materials. Multiple BOM lines can share one code and affect multiple systems. Use Base Qty, not Max Qty; zero-base options are configuration-specific. Do not invent Synergy frame/blade assembly relationships.
3. Report each matched FG, location and first at-risk week. A matched material is a *potential* FG risk, not necessarily the limiting component. Only name a constraining component and calculate `maximum buildable units = min_i floor(max(0, usable unallocated inventory_i) / base quantity_i)` after all required-component availability is known. Units unbuildable additionally need planned builds; otherwise 'not determinable'. Shared material needs planner allocation priority.
4. Sort by severity then first week; note BOM/data gaps, scenario, prior versus new data read dates and period horizon. Give qualified dated material/quantity/location checks, but don't automatically launch donor or PO investigation unless requested.
