# Best donor: compare only relevant sites, materials, weeks

1. Use the flagged materials and recipient first-risk weeks from the current question or prior conversation; mark prior-week gaps as prior-read if not refreshed. Find and verify model forecast excess measure and matching material/scenario axes. Default Scenario 1. For each material/risk week, read **all other stock-holding locations**, with material/week/scenario fixed and location as the single leaf axis; paginate until complete. Do not re-read the receiving site's entire 26-week forecast or query POs. If incomplete, label the donor ranking provisional.
2. Rank by highest modeled excess in the shortage week; show material, provisional gap, donor, receiver and target week. Model excess is not confirmed uncommitted/transferable inventory. A proposed quantity must not exceed confirmed need and confirmed donor usable stock; otherwise present the quantity as conditional requirement to check. Optionally check intervening donor weeks when a continuing transfer is proposed.
3. Actual 'best feasible' source additionally needs stock release, reservations, transit and arrival before the target week, and cross-border constraints. Without these, state 'largest-excess candidate', not fastest on-time transfer. No transfer is made.
